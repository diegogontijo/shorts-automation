# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this project does

Automated YouTube Shorts pipeline that generates a dark-narrative short video from a topic and a skull image reference. The pipeline: Claude analyzes the skull → Claude writes the script → ElevenLabs narrates → Grok (xAI Aurora) generates scene images → ffmpeg assembles the final vertical video with hook intro, transitions, subtitles, and SFX.

## Running

```bash
pip install anthropic openai requests python-dotenv pillow
python main.py "O que acontece se você nunca dormir?"
# imagem padrão: assets/caveira-de-referencia.png (pode sobrescrever com 2º arg)
```

Required `.env` variables:
- `ANTHROPIC_API_KEY`
- `XAI_API_KEY` (from https://console.x.ai)
- `ELEVENLABS_API_KEY`
- `ELEVENLABS_VOICE_ID` (optional, has default)

Output lands in `shorts_output/`.

### Música de fundo (opcional)
Coloque `assets/background.mp3` — mixada automaticamente a 15% de volume.

### SFX personalizados (opcional)
- `assets/click.mp3` — som entre clips do hook
- `assets/whoosh.mp3` — som nas transições de cena
- Se ausentes, o pipeline gera versões sintéticas via ffmpeg.

## Pipeline steps (in `main()`)

1. `analisar_caveira` — Claude vision descreve a caveira para consistência visual
2. `gerar_roteiro` — Claude gera JSON com `NUM_CENAS` cenas no estilo viral (time markers, 2ª pessoa, escalada)
3. `gerar_narracao` — ElevenLabs TTS na `narracao_completa`
4. `gerar_todas_imagens` — Grok vision + Aurora por cena (pula se já existir)
5. `gerar_legendas` — SRT com 3 palavras/bloco, offset de `HOOK_DUR` (3s)
6. `montar_video` — orquestra todas as etapas ffmpeg abaixo

### Dentro de `montar_video`

| Função | O que faz |
|--------|-----------|
| `renderizar_clipes_ken_burns` | Renderiza cada cena com zoompan (Ken Burns); cacheia por filename |
| `criar_hook_video` | Extrai 0.75s do meio das cenas 1-4 com zoom punch 108% |
| `criar_hook_audio` | 3s de silêncio + click nos cortes (t=0.75, 1.5, 2.25s) |
| `concatenar_com_xfade` | xfade `fade` de 0.15s entre as 6 cenas |
| `mixar_whoosh_na_narracao` | Adiciona whoosh (35% vol) em cada ponto de transição |
| Assembly final | Concat hook+cenas (vídeo), concat hook_audio+narração (áudio), subtitles, bg music |

## Key constants

| Name | Value | Purpose |
|------|-------|---------|
| `NUM_CENAS` | 6 | Número de cenas/imagens |
| `DURACAO_ALVO` | 55s | Duração alvo da narração |
| `RESOLUCAO_W/H` | 1080×1920 | Vertical 9:16 |
| `FPS` | 30 | Frame rate de saída |
| `HOOK_CLIP_DUR` | 0.75s | Duração de cada clip no hook |
| `HOOK_N_CLIPS` | 4 | Clips no hook |
| `HOOK_DUR` | 3.0s | Duração total do hook |
| `TRANS_DUR` | 0.15s | Duração do xfade entre cenas |

## External APIs

- **Claude** (`claude-opus-4-5`) — vision analysis + JSON script generation
- **ElevenLabs** (`eleven_multilingual_v2`) — TTS narration
- **Grok** — vision via `grok-2-vision-latest` + image generation via `aurora` (OpenAI-compatible SDK → `https://api.x.ai/v1`)
- **ffmpeg** — must be on PATH; usado para zoompan, xfade, adelay, amix, subtitle burn-in

## Script style — mandatory

All scripts generated by Claude must follow the structure in `transcripts/examples.md`. Key rules:

- **Hook question as title**: "O que acontece se você…", "Quantas X para morrer?", "E se…"
- **Second person ("você")**: the viewer lives the experience
- **Time markers as scene headers**: `Dia 1`, `Ano um`, `Hora 5`, `1 mês`, `3 anos` — escalate with the story
- **Progressive escalation**: light change → extreme consequence → irreversible endpoint
- **Short punchy sentences**: 1–2 sentences per beat, visceral sensory detail
- **No filler opener**: start mid-action on the first time marker
- **Ending**: single dramatic final sentence — shocking, visual, irreversible

## Notes

- Grok image generation uses a two-call pattern: vision call to absorb the skull reference, then `images.generate` with enriched prompt. Has 3-retry logic with 5s backoff.
- Scene images and Ken Burns clips are cached by filename — rerunning skips already-generated files.
- `gerar_legendas` uses `ffprobe` to get the real ElevenLabs audio duration and scales all timings proportionally. All subtitle timestamps are offset by `HOOK_DUR` (3s).
- `montar_video` scales clip durations by `duracao_real / DURACAO_ALVO` — audio is always the master clock.
- Total video duration = `HOOK_DUR + duracao_real - (NUM_CENAS - 1) * TRANS_DUR` (xfades consume time).
- On Windows, the subtitles filter path is escaped via `ffmpeg_path()` (backslashes → forward slashes, colon escaped).
- `roteiro.json` is saved to `shorts_output/` after each run for inspection.
- `ffmpeg_path()` and `even()` are utility helpers for Windows path safety and libx264 even-dimension requirement.
